# alcohol — 自作 飲酒記録アプリ (PWA)

ぽっち🌟さん専用の飲酒記録カレンダー(縮小版)。

## 機能

- 月別カレンダー(各日の純アルコールg + 状態絵文字)
- 日次入力(状態: 普通/やや二日酔い/二日酔い、飲酒した/してない/削除)
- 6カテゴリ(カスタム/ビール/ハイボール/チューハイ/ワイン/日本酒)
- 標準プリセット約36種(seed)
- カスタムプリセット追加・削除
- 月集計(純アル総量/休肝/適量/やや飲み過ぎ/飲み過ぎ/危険)
- JSON Export/Import

## デプロイ

Vercel で新規プロジェクト作成:
1. https://vercel.com → Add New → Project
2. cc_Garmin リポジトリ import
3. **Root Directory**: `docs/alcohol`
4. **Framework Preset**: Other
5. Deploy

完成 URL 例: `alcohol-xxx.vercel.app/`

## 配色閾値 (g/日)

| 状態 | 範囲 | 絵文字 | 背景 |
|---|---|---|---|
| 休肝 | 0 | ♥️ | 白 |
| 適量 | 1-20 | 😊 | 黄薄 |
| やや飲み過ぎ | 20-40 | 😞 | オレンジ薄 |
| 飲み過ぎ | 40-60 | 😟 | 赤オレンジ薄 |
| 危険 | 60+ | 💀 | 赤薄 |

- 月目標: 420g以内
- 休肝日目標: 月10日

## 純アルコール計算式

```
純アルコール量(g) = 容量(ml) × アルコール度数(%) ÷ 100 × 0.8
```

## データ保存

ブラウザの localStorage(キー `alcohol_data`)。
