# kakeibo — 自作 家計簿アプリ (PWA)

ぽっち🌟さん専用の家計簿。

## 機能

- **入力タブ**: 日付/項目名/金額/カテゴリ。支出/収入/振替の3種
- **一覧タブ**: 月別 日単位グルーピング、月合計表示、タップで編集/削除
- **テンプレート**: 入力欄を埋めた状態で「支出を入力する」ボタンを**長押し**で登録 → 「📋 テンプレートから選ぶ」で呼び出し/削除

## デフォルトカテゴリ

支出: 住居費🏠 / 食費🍚 / 衣服👕 / 通信費📱 / 生活用品🧴 / 趣味🎮 / 交通費🚃 / 交際費🤝 / 薬💊
収入: 給与💰 / 賞与🎁 / その他✨

## デプロイ

Vercel で新規プロジェクト作成:
1. https://vercel.com → Add New → Project
2. cc_Garmin リポジトリ import
3. **Root Directory**: `docs/kakeibo`
4. **Framework Preset**: Other
5. Deploy

## データ保存

ブラウザの localStorage(キー `kakeibo_data`)。
